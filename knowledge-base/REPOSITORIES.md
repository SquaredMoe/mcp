## Reading order

1. Open a repository's README and its `AGENTS.md` / `CLAUDE.md` (when present) for operator expectations.
2. Verify the default branch and inspect manifests (`package.json`, `pyproject.toml`, `Cargo.toml`, solution/project files, etc.).
3. Identify entry points and integration surfaces from the paths above; follow imports/calls rather than assuming architecture from folder names.
4. For forks, compare the account branch with the upstream branch before changing code; the account may be behind, ahead, or diverged.
5. Check tests, workflows, dependency/security policies, and licensing relevant to the proposed use.
